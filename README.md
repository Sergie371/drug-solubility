# Проект: Прогнозирование растроримости лекарственных препаратов

## Описание
Проект представляет собой ml-пайплайн, в котором проводится подготовка данных, обучение многих математических моделей (inear Regression, KNN, SVR, деревья решений и бустинги) и разработка прототипа, предсказывающего растворимость препарата на основе его молекулярных свойств.

## Требование к окружению
- Операционная система Linux
- Python 3.12+
- Менеджер пакетов `uv`

## Установка зависимостей
Для создания окружения и установки всех библиотек выполните в терминале:
uv sync

## Запуск проекта
Выолните команду
./run.sh chmod +x run.sh
Чтобы сделать скрипт запуска исполняемым

Проект запускается через bash-скрипт run.sh. Скрипт принимает 2 параметра:
1) random_seed — целое число для инициализации генератора случайных чисел (например, 42).
2) model_name — название модели для предсказания (например, best для автоматического выбора лучшей, либо конкретная: XGBoost, SVR, RandomForest и т.д.).

Выполните команду запуска
./run.sh 42 best
(стандартные значения)

## Описание работы Bash-скрипта
Скрипт run.sh выполняет следующие действия:
1)Проверяет наличие переданных аргументов.
2) Запускает скрипт подготовки и обучения src/train.py, передавая ему random_seed (для воспроизводимости разбиения данных и обучения деревьев).
3) Запускает скрипт предсказания src/predict.py, передавая ему имя модели. Если передано best, скрипт автоматически загрузит модель с наивысшим R2 из файла с метриками.
